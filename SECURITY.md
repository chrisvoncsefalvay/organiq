# security

Report security issues through GitHub private vulnerability reporting if it is enabled on the repository.

Do not include patient identifiers, DICOM files, screenshots containing protected health information, model checkpoints or private paths in public issues. Provide the minimal affected version, the extension action that triggers the issue and redacted logs sufficient to reproduce the behaviour.

Organiq does not require patient data in the source repository. Keep all real imaging studies, MONAI caches and generated exports outside Git and outside release archives.
